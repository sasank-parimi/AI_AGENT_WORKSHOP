Retrieval-Augmented Generation

Find the evidence first, then generate with it in context

RAG grounds a response in information retrieved for this question. It does not retrain the model.

1

Ask

Start with the current question.

2

Retrieve

Search trusted sources for the most relevant passages.

3

Add context

Attach the passages and source metadata to the request.

4

Generate + cite

Answer only as far as that evidence supports.

Without retrieval: the answer relies on the prompt and model memory.
With retrieval: current evidence becomes visible context. Weak retrieval creates weak grounding, and missing evidence stays visible.

Course-document search and live web search use the same retrieve-then-generate pattern. They differ in where the evidence comes from.
